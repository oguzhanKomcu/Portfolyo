EF Core 10 ile Vektörel Arama

"Laptop" yazan kullanıcıya "Dizüstü Bilgisayar" ürünlerini getirmek: SQL Server 2025 vector tipi ve LINQ ile anlamsal arama.

Bir e-ticaret sitesinde "laptop" diye arama yapıldığını düşünün. Ürünler ise "Dizüstü Bilgisayar" adıyla listelenmiş.

Klasik arama "laptop" kelimesini bulamaz ve sonuç: "Aradığınız kriterlere uygun ürün bulunamadı." Oysa ikisi aynı şey. Kelimeler tutmuyor ama anlam tutuyor.

Vektörel arama nasıl çalışıyor?

Yapay zeka her metne bir "anlam koordinatı" veriyor. Buna embedding (vektör) deniyor. Anlamca yakın metinler bu haritada yan yana düşüyor; "laptop" ile "dizüstü bilgisayar" neredeyse üst üste duruyor.

Model bunu bir sözlükten öğrenmiyor. Milyarlarca metinde iki ifadenin hep aynı kelimelerle (batarya, RAM, ekran...) birlikte geçtiğini görüp aynı şey olduklarını kendisi çıkarıyor.

Arama yapıldığında kullanıcının yazdığı kelime de koordinata çevriliyor ve ona en yakın ürünler getiriliyor. Yani kelimeye göre değil, anlama göre arama.

EF Core 10 ne değiştirdi?

Eskiden bunun için ayrı bir vektör veritabanı kurup ana veritabanıyla senkron tutmak gerekiyordu. EF Core 10 artık SQL Server 2025 ve Azure SQL'deki yerleşik vector tipini doğrudan destekliyor.

  • Ayrı bir veritabanı yok
  • Yeni sorgu dili yok, her gün yazılan LINQ ile devam
  • OpenAI, Azure OpenAI ya da lokalde Ollama kullanılabiliyor

Kod

// 0️⃣ Embedding üretecek yapay zeka servisini kaydet (Program.cs)
builder.Services.AddEmbeddingGenerator(
    new OpenAIClient(builder.Configuration["OpenAI:ApiKey"])
        .GetEmbeddingClient("text-embedding-3-small")
        .AsIEmbeddingGenerator());

// 1️⃣ Ürün tablosuna "anlam" sütunu ekle
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public string Description { get; set; } = string.Empty;

    // text-embedding-3-small 1536 boyutlu vektör üretir
    [Column(TypeName = "vector(1536)")]
    public SqlVector<float> Embedding { get; set; }
}

public class ProductService(
    AppDbContext context,
    IEmbeddingGenerator<string, Embedding<float>> embeddingGenerator)
{
    // 2️⃣ Ürünü kaydederken adı + açıklamayı vektöre çevir
    public async Task AddAsync(string name, string description)
    {
        var embedding = await embeddingGenerator.GenerateVectorAsync($"{name} {description}");

        context.Products.Add(new Product
        {
            Name = name,
            Description = description,
            Embedding = new SqlVector<float>(embedding)
        });
        await context.SaveChangesAsync();
    }

    // 3️⃣ "laptop" araması "Dizüstü Bilgisayar" ürünlerini getirir
    public async Task<List<Product>> SearchAsync(string text)
    {
        var query = new SqlVector<float>(
            await embeddingGenerator.GenerateVectorAsync(text));

        return await context.Products
            .OrderBy(p => EF.Functions.VectorDistance("cosine", p.Embedding, query))
            .Take(10)
            .ToListAsync();
    }
}
